An encyclopedic, structured reference to master computer science fundamentals, data structures, and algorithmic techniques from beginner level to advanced product-company interview standards.

⚡ 1. Asymptotic Analysis & Complexity Masterclass

🟢 2. Fundamental Linear Data Structures

Arrays & Dynamic Arrays

Contiguous block of memory allocation enabling O(1) random access indexing. Dynamic arrays (C++ vector, Python list, Java ArrayList) double capacity upon overflow with amortized O(1) insertions.

  • Two Pointers: Fast/slow pointers for in-place array mutation or pair sum search.
  • Prefix Sums: P[i] = P[i-1] + A[i] allows range sum queries in O(1) time.
  • Kadane's Algorithm: Max contiguous subarray sum in single O(N) pass.

Strings & Character Processing

Arrays of immutable or mutable characters. Key operations include pattern matching, substring extraction, and sliding window string parsing.

  • Sliding Window: Maintaining dynamic character frequency hash array for subsegments.
  • KMP Algorithm: String pattern matching using Partial Match Table (LPS) in O(N + M).
  • Rabin-Karp: Rolling hash mechanism for multi-pattern substring matching.

Hash Maps & Hash Sets

Key-value mappings backed by hash functions translating keys to bucket indices. Delivers average O(1) time complexity for insertion, retrieval, and removal.

  • Chaining vs Open Addressing: Resolving hash collisions via linked buckets or probing.
  • Frequency Counter Pattern: Checking anagrams, array duplicates, and complement pairs.
  • LRU Cache Architecture: Combining Hash Map + Doubly Linked List for O(1) updates.

Stacks & Queues

Linear sequence structures with restricted entry and exit policies. Stacks enforce LIFO (Last-In-First-Out); Queues enforce FIFO (First-In-First-Out).

  • Monotonic Stack: Stack keeping elements strictly increasing/decreasing for Next Greater Element.
  • Expression Parsing: Evaluating Infix, Prefix, and Postfix (RPN) mathematical expressions.
  • Deques & BFS: Double-ended queues enabling O(1) operations at both ends for sliding window max.

🟡 3. Trees, Binary Search Trees & Heaps

Binary Trees & Recursive Traversals

Hierarchical tree nodes containing data and at most two pointers (left child, right child). Recursive Depth-First Search (DFS) provides three standard traversal orders:

  • Inorder (Left-Root-Right): Yields sorted sequence when applied to Binary Search Trees.
  • Preorder (Root-Left-Right): Ideal for tree cloning and prefix serialization.
  • Postorder (Left-Right-Root): Perfect for bottom-up computation (e.g. subtree tree height/diameter).

Binary Search Trees (BST) & Self-Balancing

Binary trees upholding the BST invariant: Left Subtree < Node < Right Subtree. Operations execute in O(H) where H is tree height (O(log N) when balanced).

  • BST Insert/Search/Delete: Traversal by binary decision comparisons.
  • AVL & Red-Black Concepts: Tree rotations maintaining height balanced at O(log N).
  • LCA (Lowest Common Ancestor): Finding split point where node values bracket target keys.

Heaps & Priority Queues

Complete binary trees stored compactly in arrays where parent indices satisfy P[i] <= P[2i+1] (Min-Heap) or P[i] >= P[2i+1] (Max-Heap).

  • Heapify Operation: Building heap from unsorted array in linear O(N) time.
  • Top K Frequent Elements: Maintaining Min-Heap of size K in O(N log K) time.
  • Two Heaps Median Finding: Max-Heap for lower half + Min-Heap for upper half.

Trie (Prefix Trees)

Tree structure designed for fast character prefix retrieval. Each node contains a character child array (26 for lowercase English) and an isEndOfWord boolean flag.

  • Insert & Search: Word insertion/lookup in O(W) time where W is word length.
  • Autocomplete Engine: Finding all words matching prefix string.
  • Aho-Corasick Automaton: Multi-pattern string searching using suffix failure links.

🔴 4. Graph Algorithms, Dynamic Programming & Backtracking

Graph Representations & Traversals

Vertices (nodes) connected by Edges. Represented via Adjacency Lists or Matrices. Fundamentals include BFS for shortest paths and DFS for connectivity.

  • BFS (Breadth-First Search): Level-order queue traversal finding shortest distance in unweighted graphs.
  • DFS (Depth-First Search): Recursion stack searching deep paths, connected components, cycle detection.
  • Topological Sort: Ordering DAG (Directed Acyclic Graph) vertices via Kahn's BFS or DFS Postorder.

Shortest Path & Union-Find (DSU)

Advanced graph techniques for weighted networks and dynamic set connectivity.

  • Dijkstra's Algorithm: Single-source shortest path using Priority Queue in O((V + E) log V).
  • Bellman-Ford: Handles negative edge weights and detects negative cycles in O(V * E).
  • Disjoint Set Union (DSU): Path compression + rank union for near-constant O(α(N)) set union/find.

Dynamic Programming (DP) Masterclass

Optimization technique transforming exponential recursive problems into polynomial solutions by caching overlapping subproblems.

  • Memoization (Top-Down): Recursion + Hash/Array caching.
  • Tabulation (Bottom-Up): Iterative state-transition table building.
  • Classic DP Patterns: 0/1 Knapsack, Unbounded Knapsack, Longest Common Subsequence (LCS), Edit Distance, Coin Change.

Backtracking & Greedy Strategies

Algorithmic paradigms for decision-tree exploration and local optimization.

  • Backtracking: Recursive trial-and-error (Subsets, Permutations, N-Queens, Sudoku Solver).
  • Greedy Choice Property: Making locally optimal choice at each step (Activity Selection, Huffman Coding).
  • Bit Manipulation: Fast bitwise operations (XOR single number, bitmasks for DP states).
