An encyclopedic textbook containing formal definitions, asymptotic analysis limit formulas, data structure internal mechanics, recurrence relations, and algorithm proofs.

⚡ 1. Asymptotic Theory, Limit Definitions & Master Theorem

Formal Asymptotic Definitions

Mathematical upper, lower, and tight bounds defined using limit behavior:

  • Big-O (Upper Bound): f(N) = O(g(N)) if ∃ c > 0, N₀ > 0 such that f(N) ≤ c · g(N) ∀ N ≥ N₀.
  • Big-Ω (Lower Bound): f(N) = Ω(g(N)) if ∃ c > 0, N₀ > 0 such that f(N) ≥ c · g(N) ∀ N ≥ N₀.
  • Big-Θ (Tight Bound): f(N) = Θ(g(N)) if f(N) = O(g(N)) and f(N) = Ω(g(N)).

Master Theorem Formula

For divide-and-conquer recurrences of the form T(N) = a · T(N / b) + f(N) (where a ≥ 1, b > 1):

  • Case 1: If f(N) = O(N^(log_b(a) - ε)), then T(N) = Θ(N^(log_b a)).
  • Case 2: If f(N) = Θ(N^(log_b a)), then T(N) = Θ(N^(log_b a) · log N).
  • Case 3: If f(N) = Ω(N^(log_b(a) + ε)), then T(N) = Θ(f(N)).

🟢 2. Array, String & Hash Table Mathematics

Prefix Sum & Subarray Formulas

Precomputing running sums enables O(1) subsegment queries:

  • Prefix Sum: P[i] = P[i-1] + A[i]. Range sum Sum(L, R) = P[R] - P[L-1].
  • Kadane's Transition: dp[i] = max(A[i], dp[i-1] + A[i]).
  • 2D Matrix Prefix Sum: P[i][j] = A[i][j] + P[i-1][j] + P[i][j-1] - P[i-1][j-1].

Polynomial Rolling Hash (Rabin-Karp)

Converting string substrings into integer hashes modulo prime M:

  • Hash Formula: H(S) = (S[0]·pⁿ⁻¹ + S[1]·pⁿ⁻² + ... + S[n-1]) mod M.
  • Rolling Shift: H_new = (p · (H_old - S_old · pⁿ⁻¹) + S_new) mod M.
  • Standard Parameters: Base p = 31 (lowercase), Prime M = 10⁹ + 7.

🟡 3. Trees, Heaps & Pointer Invariants

Binary Tree & BST Formulas

Mathematical invariants for binary tree height and node capacities:

  • Full Tree Capacity: Max nodes for height H is N = 2^(H+1) - 1.
  • Minimum Height: Height H = ⌊log₂ N⌋.
  • Tree Diameter: Diameter(Node) = max(Height(Left) + Height(Right)).

Binary Heap Index Formulas

Array-based complete binary tree parent-child pointer calculations:

  • Parent Index: Parent(i) = ⌊(i - 1) / 2⌋.
  • Child Indices: Left(i) = 2i + 1, Right(i) = 2i + 2.
  • O(N) Heapify Proof: Sum ∑ (N / 2^(h+1)) · O(h) = O(N).

🔴 4. Graph Relaxation & Dynamic Programming Recurrences

Graph Edge Relaxation Formulas

Mathematical conditions for single-source and all-pairs shortest paths:

  • Dijkstra Relaxation: if d[u] + w(u, v) < d[v] ⇒ d[v] = d[u] + w(u, v).
  • Floyd-Warshall DP: d[i][j] = min(d[i][j], d[i][k] + d[k][j]).
  • DSU Path Compression: find(x) = (parent[x] == x) ? x : (parent[x] = find(parent[x])).

Dynamic Programming Recurrence Formulas

Formal DP state transition equations for optimal subproblem resolution:

  • 0/1 Knapsack: dp[i][w] = max(dp[i-1][w], dp[i-1][w-w_i] + v_i).
  • LCS String DP: dp[i][j] = (S1[i]==S2[j]) ? dp[i-1][j-1]+1 : max(dp[i-1][j], dp[i][j-1]).
  • Edit Distance: dp[i][j] = min(Insert, Delete, Replace) + 1.

Bit Manipulation Identities

Essential bitwise operators and fast binary integer identities:

  • Clear Lowest Set Bit: n & (n - 1).
  • Isolate Lowest Set Bit: n & (-n).
  • Power of Two Test: n > 0 && (n & (n - 1)) == 0.
