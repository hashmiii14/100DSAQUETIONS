⚡ Topic 1: Asymptotic Analysis & Algorithm Complexity

Formal Asymptotic Notations

Asymptotic analysis evaluates execution runtime and memory growth as input size N approaches infinity:

  • Big-O (Upper Bound): f(N) = O(g(N)) guarantees algorithm worst-case runtime never exceeds c·g(N).
  • Big-Ω (Lower Bound): f(N) = Ω(g(N)) guarantees best-case execution requires at least c·g(N) steps.
  • Big-Θ (Tight Bound): f(N) = Θ(g(N)) specifies exact growth rate matching both upper and lower bounds.
  • Amortized Analysis: Average cost over sequence of N operations (e.g. dynamic array capacity doubling).

Master Theorem for Recurrences

Used to analyze divide-and-conquer recurrences of the form T(N) = a·T(N/b) + f(N):

  • Case 1: If f(N) = O(N^(log_b a - ε)) ⇒ T(N) = Θ(N^(log_b a)).
  • Case 2: If f(N) = Θ(N^(log_b a)) ⇒ T(N) = Θ(N^(log_b a) · log N).
  • Case 3: If f(N) = Ω(N^(log_b a + ε)) ⇒ T(N) = Θ(f(N)).

🟢 Topic 2: Arrays, Dynamic Arrays & Subarray Mechanics

Array Memory Architecture

Arrays allocate contiguous RAM memory blocks, giving CPU caches maximum spatial locality and enabling instant O(1) index math: Address = Base + Index · ElementSize.

  • Two Pointers: Converging left/right pointers for sorted pair sum or palindrome verification.
  • Sliding Window: Maintaining dynamic subsegments under target constraints in O(N) time.
  • Prefix Sums: Precomputing P[i] = P[i-1] + A[i] for O(1) range queries.

Subarray Algorithms (Kadane's & Difference Arrays)

Advanced array techniques for optimal contiguous subarray selection and range update processing:

  • Kadane's Algorithm: Single-pass maximum subarray sum state recurrence: dp[i] = max(A[i], dp[i-1] + A[i]).
  • Difference Array: Range updates +V on [L, R] achieved in O(1) via D[L] += V and D[R+1] -= V.

🟢 Topic 3: Strings, Pattern Matching & Hash Tables

String Processing & KMP Algorithm

String processing algorithms for fast substring matching without redundant backtracking:

  • KMP Algorithm: Uses Longest Prefix Suffix (LPS) table to match patterns in O(N + M).
  • Rabin-Karp Rolling Hash: Polynomial hashing converting substrings to integers modulo prime M.

Hash Tables & Collision Resolution

Key-value stores mapping keys to table buckets via hash functions h(k) for average O(1) operations:

  • Chaining vs Open Addressing: Resolving collisions using linked buckets vs linear/quadratic probing.
  • LRU Cache Architecture: Combining Hash Map + Doubly Linked List for O(1) cache evicted updates.

🟡 Topic 4: Linked Lists, Stacks, Monotonic Stacks & Queues

Linked Lists & Pointer Mechanics

Dynamic node structures connected via memory pointers, avoiding pre-allocated buffer limits:

  • Floyd's Cycle Detection: Fast (2 steps) and slow (1 step) pointers meeting inside cycle.
  • In-Place Reversal: Reversing next pointers iteratively using prev, curr, next.

Monotonic Stacks & Deques

Restricted linear structures with ordering invariants for fast nearest element discovery:

  • Monotonic Stack: Maintaining ordered elements to find Next Greater Element in O(N).
  • Sliding Window Deque: Double-ended queue storing candidate max elements in O(N).

🟡 Topic 5: Binary Search Variations & Sorting Algorithms

Binary Search Invariants

Logarithmic O(log N) search halving candidate space at each step via mid comparison:

  • Lower & Upper Bounds: Identifying first and last occurrence indices of target values.
  • Search on Answer Space: Binary searching monotonic feasibility functions isValid(mid).

Sorting Paradigms & Comparators

Ordering elements by relational key comparisons or non-comparison counting buckets:

  • Merge Sort (Stable O(N log N)): Divide-and-conquer splitting and merging sorted halves.
  • QuickSort (In-Place Average O(N log N)): Partitioning array around pivot elements.

🔴 Topic 6: Trees, BST, Heaps, Priority Queues & Tries

Binary Trees & BST Traversals

Hierarchical tree node structures. Binary Search Trees enforce Left < Root < Right invariant:

  • Traversals: DFS Preorder (cloning), Inorder (sorted output), Postorder (height/bottom-up).
  • Lowest Common Ancestor (LCA): Finding first common ancestor node where paths split.

Heaps, Priority Queues & Tries

Complete binary trees stored in array buffers and character prefix retrieval trees:

  • O(N) Heapify: Building valid Heap from unsorted array in linear time.
  • Trie Prefix Tree: Character node arrays providing O(Length) word lookups.

🔴 Topic 7: Graph Algorithms, Dynamic Programming & Bit Manipulation

Graph Traversals & Shortest Paths

Network structures modeled via Adjacency Lists representing vertex-edge connectivity:

  • Dijkstra's Algorithm: Priority Queue shortest path in weighted graphs in O((V+E) log V).
  • Disjoint Set Union (DSU): Path compression + rank union for O(α(N)) set connectivity.

Dynamic Programming & Bitwise Tricks

Optimization technique caching overlapping subproblems and fast binary bitwise arithmetic:

  • DP Patterns: 0/1 Knapsack, Coin Change, LCS, Edit Distance, Longest Increasing Subsequence.
  • Bitwise Operators: Clear lowest set bit n & (n-1) and power of two test.
