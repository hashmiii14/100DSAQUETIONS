# DSA 100 LeetCode Roadmap — Hyperlinked PDF

A modified version of the original `DSA_100_LeetCode_Roadmap_CPP_Java.pdf` with **clickable hyperlinks** on every LeetCode question name.

## What's in this repository

| File | Description |
|------|-------------|
| `DSA_100_LeetCode_Roadmap_CPP_Java.pdf` | Original PDF (unchanged) |
| `DSA_100_LeetCode_Roadmap_CPP_Java_Hyperlinked.pdf` | **New PDF with clickable links** |

## How the links work

- Every question name in the PDF is a **clickable hyperlink**.
- Clicking opens the **official LeetCode problem page** directly in your browser.
- Works in: **Chrome PDF Viewer**, **Adobe Acrobat**, **Edge**, and **mobile PDF viewers**.
- Visual appearance of the PDF is **100% identical** to the original.
